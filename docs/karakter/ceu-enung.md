# Ceu Enung

| | |
|---|---|
| **Nama** | Enung Marhamah |
| **Dipanggil** | Ceu Enung |
| **Umur** | 55 |
| **Tinggal** | Desa Cipicung, Banten |
| **Hubungan** | Mantan istri [Pak Lurah](/karakter/pak-lurah), ibu [Neng Lia](/karakter/neng-lia) |
| **Ciri** | kerudung sederhana, wajah teduh, senyum tipis |

Ceu Enung tidak tinggal di kampung. Ia muncul lewat **pesan WhatsApp**, biasanya saat Pak Lurah
lupa makan.

## Latar cerita

Enung menemani Rohimin dari nol sampai ia jadi tangan kanan kantor desa Cipicung. Lelah
menunggu suami yang selalu memilih desa daripada rumah, ia mengajukan cerai di 2019, tanpa
dendam.

Sekarang ia berjualan lontong dan bala-bala di Cipicung. Ia tidak pernah menghubungi Rohimin
lebih dulu, kecuali kalau tahu Rohimin lupa makan. Diam-diam ia bangga pada Kampung Cianj.AI.

## Sifat

- Tenang, blak-blakan, hangat, tapi tidak mau dikasihani.
- Tidak pernah menjelekkan Rohimin.

## Cara bicara

Bahasa Sunda halus, kalimat pendek dan langsung ke inti, sering ditutup "atuh". Memanggil
"Akang" hanya saat marah-marah sayang.

> Kang, udah makan? Jangan kopi doang atuh

> Kampungnya rame katanya? Alhamdulillah

> Lia nelepon, kamu jangan bohong lagi

## Kapan muncul

- Pesan WA saat Pak Lurah lupa makan
- Hari raya, saat Pak Lurah pulang sebentar ke Cipicung
- Saat Neng Lia pulang dari Taiwan dan mereka duduk bertiga
